# セキュリティポリシー

## 脆弱性の報告

セキュリティ脆弱性を公開Issueで報告しないでください。

[非公開の報告窓口]から報告してください。影響を受けるバージョン、再現手順、影響、判明している緩和策を含めてください。[期間]以内に受領確認を行い、[期間]以内に状況を更新します。

報告には資格情報、個人データ、無関係な機密情報を含めないでください。
