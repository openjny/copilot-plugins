# gantt-chart

ガントチャートを編集できる canvas (`openjny-gantt-chart`) を追加するプラグインです。チャートは 1 つの JSON ファイルに保存されます。ユーザーは画面で、エージェントは action で、同じファイルを編集します。画面は日本語と English に対応し、操作は元に戻す・やり直しができます。

<img width="1670" height="1059" alt="image" src="https://github.com/user-attachments/assets/98ce66e0-462a-42d2-b4bc-ab1a236fdc89" />

## 開き方

エージェントに「`plan.gantt.json` でガントチャートを開いて」と頼むか、canvas を開いて画面でパスを入力します。存在しないパスを指定すると、新しいチャートを作ります。拡張子は `.json` にしてください。

> [!NOTE]
> 2.0.0 でファイル形式を作り直しました（[ファイル形式](#ファイル形式)）。1.x のファイルは読み込めません。

## 画面でできること

| 操作 | 方法 |
|:--|:--|
| 元に戻す・やり直し | ツールバーの矢印ボタン、または Ctrl+Z（元に戻す）と Ctrl+Y / Ctrl+Shift+Z（やり直し）。ボタンのヒントに、何を戻すかが出ます。画面で行った編集も、エージェントの `edit_chart` も、ファイルを外から書き換えた変更も、1 つずつ戻せます。履歴は最大 100 件で、ファイルを開き直すと消えます。入力欄の中の Ctrl+Z は、その欄の取り消しです |
| タスクの追加・削除・インデント・並べ替え | ツールバー。タスク名の列を開いているときは、一覧のキー操作（矢印、Enter、Delete）も使えます。Alt+↑ / Alt+↓ で選択中のタスクを上下に動かします |
| 好きな位置にタスクを挿入 | 「#」（行番号）にポインターを置くと、行の上端と下端に「+」が出ます。押すと、その位置に同じ階層のタスクが入り、詳細パネルのタスク名にカーソルが入ります。展開した親タスクの下の「+」は、そのフェーズの先頭の子タスクになります。畳んだ親タスクの下の「+」は、フェーズ全体の後ろに入ります |
| 親タスクの折りたたみ | 親タスクのバー（両端が下に尖った太い線）をダブルクリックすると、子タスクを折りたたみます。もう一度ダブルクリックすると展開します。折りたたんだ親タスクには、名前の前に「▸」が付きます（タスク名の列を閉じていても、折りたたまれていることがわかります）。右クリックメニューの「折りたたむ / 展開」でも同じです。タスク名の列を開いているときは、行頭の▸▾ボタンでも切り替えられます。列の中のダブルクリックは、名前の変更のままです |
| 右クリックメニュー | バー、一覧の行を右クリックします。上・下に挿入、子タスクを追加、複製（Ctrl+D。子タスクごと。先行タスクは引き継ぎ、コピー同士のつながりはコピーどうしでつなぎ直します）、インデント、アウトデント、上下の移動、マイルストーンへの切り替え、色ラベル、削除が出ます。複数選択中は、複製、色ラベル、削除が選択中のすべてに効きます（親タスクと子タスクを一緒に選んだときは、親タスクだけが対象です）。依存関係の線を右クリックすると「依存関係を削除」です。メニューの外をクリックしたとき、Esc、スクロールで閉じます。↑↓ キーで項目を選べます |
| マイルストーン | 1 稼働日の節目は、バーではなく◆で描きます。右クリックメニューの「マイルストーンにする」、または詳細設定の「マイルストーン」で切り替えます。期間は 1 日に固定です。ドラッグで動かせて、依存関係の線は◆の先端につながります。子タスクを持つタスクにはできません |
| 名前の変更 | 詳細パネルの見出しにあるタスク名を直接書き換えます。タスク名の列を開いているときは、タスク名のダブルクリックでも変更できます |
| 詳細の表示 | タスク（バー、一覧の行）をクリックすると、画面の下に詳細パネルが開きます。パネルは内容の分だけの高さで、チャートをなるべく隠しません。×か Esc で閉じます。開いている間は、矢印キーでの選択にも追従します |
| 詳細パネルの段階表示 | 最初に出るのは、いちばん使う「進捗」「工数」「メモ」だけです。見出しの「詳細設定」を押すと、日程（開始・終了・期間）、マイルストーン、担当、色ラベル、先行タスクが下に開きます（高さは、ドラッグで変えるまでは画面の約 4 分の 1 までです。それ以上はパネルの中でスクロールします）。開閉の状態は、次に選ぶタスクにも引き継がれます |
| クリックしたタスクを見える位置へ | タスクをクリックすると（バー、一覧の行、キー操作）、画面の外にあるタスクは横スクロールで見える位置に来ます。左にあるタスクは終了日の右に余白が付く位置に、右にあるタスクは開始日の左に余白が付く位置に動きます。収まるときはタスク全体が見えます。すでに見えているタスクは動かしません。ドラッグしたときはスクロールしません |
| 日付の移動・期間の変更 | バーをドラッグ（右端で期間を変更）。タイムラインの端にポインターを寄せると、自動でスクロールします |
| 複数のタスクを選ぶ | Ctrl+クリックで追加・解除、Shift+クリックで範囲を選択（バーでも一覧の行でも）。何もない場所からドラッグすると、四角で囲んだバーを選べます（Ctrl を押しながらだと追加）。Esc で 1 件に戻します |
| 複数のタスクを一緒に動かす | 選択中のバーを 1 つドラッグすると、全部が相対位置を保ったまま同じ稼働日数だけ動きます。親タスクのバーをドラッグすると、子タスクがまとめて動きます。どれかが先行タスクの終了前になる動きは、その手前で止まります。複数選択中は、インデント・並べ替えは使えません（削除、複製、色ラベルは選択中のすべてが対象です。削除は、親タスクや複数件のとき確認が出ます） |
| 依存関係をつなぐ | 選択中のバーの上か下にポインターを寄せると、半透明の灰色の三角が出ます（左右は期間の調整に使うので出しません）。三角は色ではなく向きと文字で区別します。上の「▲ 先行」は先行タスク（このタスクの前に済ませるもの）、下の「▼ 後続」は後続タスク（このタスクの後に始めるもの）につなぎます。三角はポインターに合わせてバーに沿って動きます。別のタスクへドラッグするか、三角をクリックしてからタスクをクリックするとつながります。Esc で取り消します。重複や循環になる相手は理由を出して断ります。親タスクは先行タスクを持てないので、下の「▼ 後続」だけです |
| 進捗・工数・メモ | 下の詳細パネル（開いてすぐ入力できます） |
| 担当の入力 | 詳細設定の「担当」は、タグ入力です。担当者が丸いチップ（×で外せます）で並び、欄をクリックすると、チャートですでに使われている担当の一覧が出ます（使っているタスクの数つき。もうチップになっているものは出ません）。入力すると検索して絞り込みます。一覧になければ、いちばん下に「『○○』を作成」が出ます。↑ ↓ で選び、Enter かクリックで追加します。「,」か「、」を打つと、入力した文字のまま追加します（似た名前があるときに、新しく作るのに使います）。何も入力していない欄で Backspace を押すと、最後のチップを外します。Esc は、まず一覧を閉じ、次にパネルを閉じます。選ばずに欄から離れると、入力した文字は捨てます。日本語入力の変換中は、Enter を変換の確定に使います。パネルが画面の下にあるときは、一覧は欄の上に開きます |
| 日程・マイルストーン・色ラベル・先行タスク | 下の詳細パネルの「詳細設定」 |
| 拡大・縮小 | Ctrl+スクロール（トラックパッドのピンチも）で、横（1 日の幅）と縦（行の高さ）を同時に拡大・縮小します。ポインターの下の日付と行は動きません。倍率に合わせて、日・週・月の表示が自動で切り替わります（ヘッダーのボタンが、いま使っている単位を示します）。キーボードでは Ctrl+↑ が拡大、Ctrl+↓ が縮小です。入力欄にフォーカスがあるときは使えません |
| 日・週・月の切り替え | ヘッダーの「日 / 週 / 月」を押すと、その単位の標準の倍率に戻ります（拡大・縮小もリセットされます）。表示の中央にある日付は保たれます |
| 過去・未来へのスクロール | タイムラインは、最初のタスクより前、最後のタスクより後ろにも、少なくとも 1 画面分の余白があります。左右どちらの端までスクロールしても、日付の範囲が自動で延びます |
| 依存関係の確認 | 依存関係の線と矢印は灰色です。タスクを選ぶと、そのタスクに出入りする線が濃い灰色で強調され、他の線は薄くなります。線は、同じタスクに出入りするものどうしが重ならないように配置されます。線の太さ、矢じりの大きさ、曲がる位置の間隔は、拡大・縮小（行の高さ）に比例して変わります |
| 依存関係（矢印）の選択・編集・削除 | 矢印をクリックすると、その 1 本だけが選ばれ、画面下のパネルでラグ（稼働日）を直せます。「この依存関係を削除」、Delete キー、ツールバーの削除ボタンで、その矢印だけを消せます。Esc で選択を外します |
| 色ラベル | ツールバーの色のボタン（いまの色が丸で出ます）から、色の一覧を開いて選びます。右クリックメニューの色の丸でも選べます。親タスクの色は、配下のタスクの既定の色です（色が「なし」のタスクは、その色で表示されます）。親に色を付けると、配下のタスクに個別に付けた色は「なし」に戻ります。タスクに個別に付けた色は、そのタスクだけ優先されます。親タスクの行から最後の子タスクの行までの背景は、親タスクの色の薄い長方形で塗られます（畳んだ親タスクにはありません） |
| 今日の位置・全体表示 | 開いたときは、今日の位置が表示されます。タイムライン右下の丸いボタンが 2 つあります。下の今日のアイコンは、横スクロールを今日の位置に戻します。上の枠のアイコンは、プロジェクト全体が横幅に収まる倍率にして、先頭へ動きます |
| タスク名・期間・担当の表示・非表示 | ツールバー左端のボタン（VS Code の左パネルと同じ形）で切り替えます。「#」（行番号）は常に左に表示します。既定は畳んだ状態で、タイムラインが広がり、バーにタスク名が出ます。開くと、タスク名・期間・担当が「#」の右に出ます |
| 列の幅 | 一覧を開くと、各列の右端にチャートの高さいっぱいの境界線が出ます。ドラッグすると、その列（タスク名・期間・担当）の幅が変わり、一覧全体の幅も変わります（タイムラインの余白を残すため、上限があります）。ダブルクリックで標準の幅に戻り、境界線にフォーカスして ← → キーでも動かせます。幅は画面を開いている間、覚えています |
| 詳細パネルの高さ | パネルの上端をドラッグすると、高さを変えられます。ダブルクリックで、内容に合わせた高さに戻ります（↑ ↓ キーでも動かせます）。高さは、次に選ぶタスクにも引き継がれます |
| プロジェクト名 | ヘッダーのプロジェクト名をダブルクリックすると、その場で書き換えられます。Enter か、欄から離れると保存し、Esc で取り消します。名前を空にすると、ファイル名を表示します。名前の右の設定ボタンで、プロジェクト設定（名前・休日）のダイアログを開きます |
| メニュー（右上の「…」） | バージョン（保存した状態に戻す）、JSON エクスポート（バージョンは含みません）、言語、表示テーマを開きます。ヘッダーには、保存の状態と、日・週・月の切り替えだけを置いています |
| ダイアログ | プロジェクト設定、バージョン、確認のダイアログは、外側の暗い部分をクリックしても閉じます（Esc と同じで、確認には「いいえ」と答えたことになります）。欄の中から押して外で離したときは閉じません |
| 言語 | 日本語と English です。メニューの「言語」で選びます。既定の「自動」はブラウザーの言語に合わせます。画面の文言、日付の表記、サーバーやエージェントに返るエラーメッセージが、選んだ言語になります。選択は保存され、次に開いたときも使われます |
| ライト・ダーク | メニューの「表示テーマ」（自動は OS の設定に合わせます） |
| タスクがないとき | チャートの中央に「タスクを追加」のボタンが出ます |

## 日程の決まり方

- 期間は稼働日で数えます。土曜、日曜、プロジェクトの休日は稼働日に含めません。`1w` は 5 稼働日です。
- 先行タスクがあるタスクは、先行タスクの終了の翌稼働日にラグ（稼働日、0 以上）を足した日に始まります。バーを動かすと、開始日ではなくラグが変わります。先行タスクの終了前に開始する変更は、ドラッグ、詳細パネル、action のいずれでも、先行タスクが許す最初の日に補正されます。負のラグは受け付けません。
- 子タスクを持つタスク（親タスク）の日付、進捗、工数は、子タスクから自動で決まります。進捗は子タスクの期間で重み付けします。
- 先行タスクが循環する変更は受け付けません。

## ファイル形式

形式の定義は [JSON Schema](./extensions/gantt-chart/schema/gantt-chart.schema.json)（draft 2020-12）です。`format` と `version`（いまは 2）で判定します。スキーマに合わないファイルや、違うファイル、別の version は、上書きせずに画面へエラーを出します。エラーには、どこがどう違うかが出ます（例: `tasks[1].children[0].duration（タスク p1-driver） は 1 以上にしてください。`）。外部での変更は約 1 秒で画面に反映されます。

タスクは木です。子タスクを持つタスク（親タスク）は `children` を持ち、開始日・期間・進捗・工数は持ちません（子タスクから決まります）。子タスクを持たないタスク（葉）は `start` と `duration` を持ちます。1 タスクが 1 行なので、直接編集も差分も読みやすくなっています。値が既定のとき（進捗以外）は省略します。

```json
{
  "$schema": "https://raw.githubusercontent.com/openjny/copilot-plugins/main/plugins/gantt-chart/extensions/gantt-chart/schema/gantt-chart.schema.json",
  "format": "openjny-gantt-chart",
  "version": 2,
  "project": {"name":"新製品","holidays":["2026-11-23"]},
  "tasks": [
    {"id":"t1","name":"設計","children":[
      {"id":"t2","name":"要件定義","start":"2026-11-16","duration":2,"progress":0},
      {"id":"t3","name":"基本設計","start":"2026-11-18","duration":2,"progress":0,"predecessors":[{"task":"t2"}]},
      {"id":"t4","name":"設計完了","start":"2026-11-24","duration":1,"progress":0,"milestone":true,"predecessors":[{"task":"t3","lag":1}]}
    ]}
  ]
}
```

| 項目 | 内容 |
|:--|:--|
| `id` | 英数字・`_`・`-` の 1〜32 文字。ファイル内で重複できません |
| `start`, `duration` | 開始日（`YYYY-MM-DD`）と稼働日数（1〜3650）。先行タスクがあるタスクの開始日は、先行タスクから決まります |
| `predecessors` | `{ "task": id, "lag": 稼働日 }` の配列。`lag` は 0 以上で、既定は 0 です |
| `milestone` | `true` で、1 日の節目（期間は 1 に固定） |
| `resources`, `color`, `note` | 担当、色ラベル（`none`, `green`, `orange`, `red`, `purple`, `teal`, `gray`）、メモ |
| `collapsed` | 親タスクだけ。一覧で畳みます |
| `versions` | 保存したバージョン（`id`, `name`, `createdAt`, `project`, `tasks`） |

スキーマでは確かめられないこと（id の重複、存在しない先行タスク、自分自身を先行タスクにすること、先行タスクの循環）は、読み込むときにプログラムが確かめます。階層は 9 段まで、タスクは 2000 件まで、バージョンは 100 件までです。

エディターで検証と補完を使うには、ファイルの先頭の `$schema` のとおりにします（`$schema` は保存のたびに書き込まれます）。VS Code の `json.schemas` にスキーマのパスを指定してもかまいません。

## エージェント向け action

| action | 内容 |
|:--|:--|
| `open_chart` | ファイルを開く（なければ作成） |
| `get_chart` | 全タスクの計算済みの日付、進捗、ユーザーが選択中のタスク（複数なら全部）を読む |
| `edit_chart` | 編集をまとめて適用する（途中で失敗したら何も変えない）。ユーザーは画面で元に戻せます |
| `reload` | ファイルを読み直す |

`edit_chart` の `ops` は `add`、`update`、`delete`、`duplicate`、`move`、`indent`、`outdent`、`shift`、`slide`、`project`、`save_version`、`restore_version`、`delete_version` です。`slide` は `ids` で指したタスク（親タスクは子タスクをまとめて指す）を、相対位置を保ったまま `days` 稼働日だけ動かします。先行タスクの終了前になる分は切り詰めて、結果の `adjusted.days` に動かした日数を返します。`duplicate` は子タスクごと複製し、結果の `copy` に新しいタスクの id を返します。`add` と `update` の `milestone` で、マイルストーンにできます。項目は action のスキーマに書いてあります。エラーメッセージは、画面で選んでいる言語で返ります。

## 保存先

チャートは指定した JSON ファイルです。最近開いたファイルの一覧を `<copilot-home>/extension-data/openjny-gantt-chart/recent.json` に、選んだテーマと言語を同じ場所の `theme.json` と `locale.json` に保存します。
