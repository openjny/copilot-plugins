# skills

Public GitHub Copilot agent skills.

## Available skills

- [`council/`](council/SKILL.md) — Aggregate opinions from multiple LLM models in parallel to reach a conclusion on complex or multi-perspective problems.
- [`grilling/`](grilling/SKILL.md) — Interview the user relentlessly about a plan or design to stress-test it before building.
- [`plan-skill/`](plan-skill/SKILL.md) — Iterative planning methodology (Discovery → Alignment → Design → Refinement) that produces an actionable plan without executing it.
